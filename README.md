# 진학 나침반

서울권 15개 대학의 이공계 진학 정보를 탐색하고 나의 목표·주간 실천·성적 변화를 기록하는 반응형 정적 웹입니다.

**웹:** https://leegunsoodev.github.io/seoul-campus-roadmap/

## 시작하기
1. 대학 탐색에서 관심 대학의 **목표·성적 자세히**를 누릅니다.
2. 2025 실제 성적 사례와 2030 준비 학습 방향을 구분해서 읽습니다.
3. **나의 목표로 정하기**를 누르고, 나의 목표 화면에서 주간 미션을 체크합니다.
4. 실제 고교 성적이 생기면 내신 또는 모의고사 기록을 남깁니다.
5. **기록 백업** 파일을 다른 기기에서 불러오면 이어서 사용할 수 있습니다.

휴대폰 Chrome의 ‘홈 화면에 추가’, iPhone/iPad Safari의 공유 → ‘홈 화면에 추가’로 바로가기를 만들 수 있습니다. 인터넷 연결이 필요합니다.

## 정보의 범위
- 대상 가정: 2026 중3 → 2027 고1 → 2030학년도 입학.
- 15교는 공식 순위가 아닌 탐색 표본. 성균관 이공계(수원), 경희 공학(용인) 등 캠퍼스 차이 표시.
- 모든 과거 사례는 2025학년도 대표 모집단위 하나의 수시·정시 결과. 2026 평가기준 자료 안의 2025 결과를 사용. 이공계 전체 평균이나 최신 모든 연도 결과가 아님.
- 9등급 과거 내신을 5등급 합격선으로 변환하지 않음. 동국대 수시는 평균, 다른 수시 사례는 70%컷. 정시 대학별 환산점수는 직접 비교 불가.
- 미래 연습 목표는 편집상 제안. 합격 확률·예측 컷·보장선이 아님. 2030 최종 요강으로 재확인 필요.
- 공식 출처: 교육부, 대입정보포털 어디가 및 각 입학처. 상세 화면의 직접 링크와 `data-evidence.json` 참조. 확인일 2026-10-23.

## 개인정보와 저장
서버 계정·광고·분석 도구 없음. 사용자 성적·메모·미션은 해당 브라우저 localStorage에만 저장됩니다. 다른 기기와 자동 동기화하지 않습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있습니다. 백업 파일은 개인 성적이 담기므로 안전하게 보관하세요. Git 저장소에는 실제 사용자 성적을 포함하지 않습니다.

## 개발
Node.js 20 이상 권장. 외부 npm 의존성 없음.
```
npm test
npm start
```
http://127.0.0.1:4173 에서 확인합니다. HTML/CSS/ES modules이며 GitHub Pages에서 별도 빌드 없이 실행됩니다. 폰트는 Google Fonts를 사용하고 연결 불가 시 시스템 글꼴로 표시합니다.

`data.mjs`: 대학·학습 방향·로드맵 / `data-evidence.json`: 근거 있는 과거 사례 / `core.mjs`: 검증·계산 / `app.mjs`: UI·저장.
